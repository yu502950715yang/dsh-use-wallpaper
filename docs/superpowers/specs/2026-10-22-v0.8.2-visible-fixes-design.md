> 日期：2026-10-22 ｜ 基线：`master` @ `v0.8.1`（`532a532`）
> 上游：本机 43 张壁纸审计 [`docs/2026-10-20-library-feature-gap-audit.md`](../2026-10-20-library-feature-gap-audit.md)（F2 / F12 / F13 / F18）

## 1. 目标与非目标

**目标**：补齐 4 张场景壁纸的「全屏后处理层」可见缺口，并修掉 text 亮度/定位/换行、image 偏色/对齐、效果 shader 指针 uniform 三类局部差异。

**不做**（留 v0.9+）：
- F12 的 `backgroundcolor`/`opaquebackground`、`text.script` 的 `init()`（含 `1922570576` 的 3D Clock 阴影层）；
- F13 的材质语义（`blending`/`cullmode`/`combos`——本机库无可见差异）；
- F1 子粒子、F5 用户属性、F9 粒子高级特性、F10 剩余脚本 API、F11 音频可视化、F16/F17 web/video；
- 点击交互（按 2026-10-20 产品决策不做转发）。

## 2. F2 util 层设计

### 2.1 数据模型

- scene.json 中 `image` 指向 `models/util/*` 的对象解析为 `SceneUtilObject`（`kind: 'util'`）：
  - `layerKind: 'project' | 'fullscreen' | 'compose' | 'solid'`（按 `image` 文件名判定；errata：素材用文件名标记，无需独立 `projectlayer` 字段）；
  - `effects`、`visible`、`alpha`、`color`、`brightness`、`size`、`scale`、`origin`、`parent` 按既有字段解析。
- 图层材质最小集：`passthrough`（project/fullscreen/compose 的默认直通内容，首帧透明占位）与 `solid`（纯色，取 color/alpha）；`util/white` 等纹理槽复用 `effect-runner` 的 builtin texture 解析，不另建材质表（errata：v0.8.2 按此缩窄，无独立 white/black/compose 材质文件）。
- 未知 `layerKind` → 按 `fullscreen` 降级（不额外 warn；诊断缺口记 AGENT §7.42）。

### 2.2 渲染模型

- 每个 util 层复用**隔离对象**路径（`addBackground` + isolate + `ObjectEffectStage` + `setObjectOutput` 合成），不写第二套渲染器：
  - `project` / `fullscreen`：world = 正交场景尺寸（强制居中、scale=1、size=场景），RT = `world × 屏幕密度`（屏占位、与 world 等比）。**errata**：原写「RT = 画布缓冲尺寸」，但 cover 裁切/竖构图场景（2597392171 场景 3840×6000）下画布比例会拉伸效果 mask，故按屏占位等比口径；
  - `compose` / `solid`：world = `size × |scale|`（有限尺寸），RT = 屏占位（与 image 同口径）；
  - util RT 均不参与 `fitIsolatedBudget`（挂载期与 resize 期一致：resize 只用 budgeted=image 条目算预算）；
  - 层内容 = 内置 util 材质（compose 直通/叠加、solid 纯色、project/fullscreen 直通），效果链复用 `EffectRunner`；
  - 绘制顺序 = 按 scene.json 对象顺序穿插（renderOrder = objects 下标；**errata**：原写「普通对象之后统一」不符合 WE 图层顺序语义）；
  - 对象 `alpha` 作用于内容与合成 quad 输出（自产 alpha 的链也受对象 alpha 约束；solid 的 0<alpha<1 存在 alpha²，T3 统一口径）。
- 层间传递：前一个 util 层的输出作为后一个 util 层的 `previous`/背景副本输入；首个 util 层输入 = 主场景快照（见 2.3）。
- solid 层：纯色 quad（不建效果链时直通合成）。

### 2.3 整帧快照与层内容输入

- util 层登记为帧消费者（`player.registerFrameConsumer(utilId)`）：`renderSegmented` 在该层绘制前拍快照。
- **快照是 util 链的「内容输入」**（真实素材的 util 效果读 `bind: previous`/层内容，而不是 `_rt_FullFrameBuffer` 槽）：段边界把快照写入该层内容（替换 passthrough 透明占位），效果链从快照开始处理；`_rt_FullFrameBuffer` 槽门控（`allowFrameSnapshot`）仅当链显式引用该槽时绑定，对象链保持关闭。
- 坐标映射：快照 = 画布 UV；全屏 util 层 RT 为场景等比 → 内容材质按 cover 变换映射（2597392171 竖构图需验证无拉伸）。
- util 最终 alpha 语义：对象 alpha 作用于合成 quad；自产 alpha 的链（3789452668 audioline）在对象 alpha=0 时应不可见（DoD 验收）。
- 快照不可用（readPixels/copy 失败）→ util 层跳过绘制 + 一次 warn（主场景不受影响）。

### 2.4 性能/预算

- 全屏 RT = 画布缓冲尺寸（4K 下约 33 MB/层），效果链 `fbos` 按素材 `scale` 降采样；
- 4 层 + ping-pong 在 `2911105183` / `2132420420` 上实测 GPU 与帧率（1080p ≥30 fps 门槛沿用）；
- 超预算时允许 util 层 RT 降到 1/2 分辨率（合成线性放大，接受轻微软）；实现上把「util RT 分辨率比例」做成常量，按实测调整。

## 3. F12 text 可见最小集

- 解析 `alpha`、`brightness`、`anchor`、`limitwidth`、`maxwidth`，存进 `SceneTextObject`（`limitrows` 不做，留 v0.9）。
- 应用：
  - `anchor`/`limitwidth`/`maxwidth` → `text-object.ts` 的布局与绘制（超宽换行/缩放；锚点决定 quad 原点）；
  - `alpha` → 层透明度；`brightness` → 颜色乘系数（>1 增亮，canvas 侧用叠加绘制近似）；
  - 直渲与隔离合成 quad 两条路径行为一致（隔离路径在合成 quad 上应用 alpha/brightness）。
- 命中：`2911105183`、`3765967112`、`3789452668`、`2460786246`、`3814332254`。

## 4. F13 image color / alignment

- `color`：image 材质的颜色 tint 乘到纹理（普通 mesh 与隔离合成 quad 两条路径）。
- `alignment`：`bottomright` 等对齐影响 quad 原点/偏移（`2937346640`）；缺省 center 行为不变。
- 材质 `blending`/`cullmode`/`combos` 不碰（按用户决策）。

## 5. F18 全局 uniform 注入

- 效果 shader 注入 `g_PointerPosition` / `g_ParallaxPosition`（归一化指针位置），复用现有 pointer tracker；
- 值语义按 `3780477933` 的 shader 反推（归一化 [0,1]，y 方向按 shader 采样约定），真机 A/B 校准；
- 每次 pass 绑定时注入（effect-runner 的 uniform 设置路径），直渲与隔离链均生效。

## 6. 错误处理与降级

| 场景 | 行为 |
|---|---|
| util 材质/层类型未知 | 按 fullscreen/直通降级 + 一次 warn |
| util 效果链编译失败 | 该层跳过或直通 + 告警（不阻断主场景） |
| 整帧快照失败 | util 层跳过绘制 + 一次 warn |
| util RT 超预算 | 降 1/2 分辨率重试（常量可调） |
| text/image 字段非法 | 忽略该字段（走缺省），不抛错 |
| 全局 uniform 缺失 | 保持现状（不注入即不变） |

- **e2e 像素判据**（新增 `e2e/verify/verify-v082.mjs`，生产入口、冻结时钟）：

  - `2132420420`：脉冲光层 on/off 的暖色亮度差；

- **真机清单**：`TESTING.md` 新增 §2.15（2911105183、2132420420、2597392171、3789452668、3765967112、3780477933、2937346640），含对照桌面 WE 的观感项。

## 8. 风险与边界

1. `_rt_FullFrameBuffer` 快照消费重启后必须用像素判据钉住全屏 UV（对象链继续关闭）。
2. composelayer 语义无参考实现（research 已清理）：按素材字段 + 真机 A/B 校准；不确定处按「全屏后处理」近似并在 AGENT §7.42 记边界。
3. 4K 全屏 RT × 4 层的显存/帧率需实测（2911105183、2132420420），超预算降分辨率。
4. F12/F13 字段细节（anchor 枚举、limitwidth 缩放 vs 换行）以素材 + 真机为准，不确定处记边界。
5. 若性能拖垮 2911105183：先保 projectlayer（2911105183）可用，再修其余三类（实现顺序在计划里体现）。
6. 本版不改 `ENABLE_CHAIN_FRAME_SNAPSHOT_CONSUMER` 的全局语义：新增 util 专用开关，旧对象链门控保持不变。
