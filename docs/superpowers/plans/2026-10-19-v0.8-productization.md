# v0.8 产品化补齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把竞品分析里 6 个 P0 产品缺口补到「可日常使用」：多级降级链、视频编码兜底、显示效果面板、自动轮播、壁纸库管理、用户属性面板；不改 scene 渲染语义。

**Architecture:** 降级链由 host 侧按需探测 `.tex` 内嵌 MP4 + client 首帧抓帧（readPixels→PNG）实现；轮播/库管理/属性覆盖值放 client 侧（localStorage + 纯函数模块），新增设置字段走既有 DSH 双版本 settings；抓帧 PNG 落 host 数据目录。所有新监听/定时器纳入既有 teardown 生命周期。

**Tech Stack:** TypeScript strict（ESM）、React 18（`settings-section.tsx`）、three.js（WebGL2）、Cordis host 插件、vitest（node + jsdom）、esbuild、Rust/WASM（v0.8 不改）。

**Spec:** `docs/superpowers/specs/2026-10-19-v0.8-productization-design.md`
**需求依据：** `docs/2026-10-19-competitor-analysis.md` §5 P0；`docs/competitive-2026-10-19/we-product.md` §4.1

## Global Constraints

- **scene 渲染语义零改动**：不碰坐标/行序/混合模式/RT/效果链；本计划只加「失败后的回退」与产品面。
- **设置字段双写**：每个新字段同时加到 `src/host/settings.ts`（schemastery）与 `src/client/types.ts` + `src/client/settings.ts`（`DEFAULTS`），并补 schema 往返测试。
- **壁纸目录只读**（用户明令，AGENT §6）：任何代码不得修改 workshop 目录内的文件；抓帧写入插件自己的数据目录。
- **生命周期**：新增 `setTimeout`/`addEventListener`/`requestAnimationFrame` 必须在 `index.ts` 的 `teardown` 里撤销；HMR 重挂载后只允许一份。参考 `autoRetryTimers` 的既有模式（AGENT §5.43）。
- **不新增运行时依赖**：不引入 ffmpeg、IndexedDB 库、状态管理库；`localStorage` 读写用 `src/client/local-store.ts` 统一封装。
- **产物入库**：`lib/`（tsc 产物）与 `dist/client.js`（esbuild 产物）在提交里必须同步更新（AGENT §3.2）。本计划不改 Rust，不需要 `build:wasm`；若 `wasm/pkg` 缺失再补跑。
- **提交纪律**：简体中文；标题一行 `type(scope): 中文标题`；正文最多 3 行；不贴实验数据（AGENT §6）。
- **测试**：每个任务先写失败测试再实现；命令用 `npx vitest run tests/<file>`；最终跑 `npm test` / `npm run verify:local`。测试需完整权限（否则 vitest/esbuild spawn EPERM，AGENT §5.13）。
- **注释从简**：一行说清「是什么/为什么」，最多 2 行；根因与实测写进 `AGENT.md`/`docs/`。

// 浏览器侧 localStorage 封装：无存储环境（node/SSR）静默降级，损坏值回退 fallback。
export interface StorageLike { getItem(k: string): string | null; setItem(k: string, v: string): void; removeItem(k: string): void; }
export const STORAGE_KEYS = { favorites: 'we:fav', hidden: 'we:hidden', recent: 'we:recent' } as const;

function storeOf(store?: StorageLike): StorageLike | null {
  if (store) return store;
  return typeof localStorage !== 'undefined' ? localStorage : null;
}
export function loadJson<T>(key: string, fallback: T, store?: StorageLike): T { /* try JSON.parse，异常返回 fallback */ }
export function saveJson(key: string, value: unknown, store?: StorageLike): boolean { /* try setItem；返回是否成功 */ }
export function loadStringSet(key: string, store?: StorageLike): Set<string> { /* loadJson<string[]> → Set，过滤非 string */ }
export function saveStringSet(key: string, ids: Iterable<string>, store?: StorageLike): void { /* [...new Set(ids)] → saveJson */ }
```

`src/host/data-dir.ts`：

import { mkdirSync } from 'node:fs';
import { homedir } from 'node:os';
import { join } from 'node:path';
export const DATA_DIR_ENV = 'DSH_USE_WALLPAPER_DATA_DIR';
export function resolveDataDir(opts: { env?: NodeJS.ProcessEnv; home?: string } = {}): string {
  const env = opts.env ?? process.env;
  const explicit = env[DATA_DIR_ENV]?.trim();
  return explicit ? explicit : join(opts.home ?? homedir(), '.dsh-use-wallpaper');
}
export function ensureDataDir(dir: string): string { mkdirSync(dir, { recursive: true }); return dir; }
export function framesDirOf(dataDir: string): string { return join(dataDir, 'frames'); }
```

// 只在 .tex 头 204B 内找合法 mp4 box（ftyp）；视频纹理标志 = flags bit5（AGENT §5.23）。
export function findEmbeddedMp4(entry: Uint8Array): { offset: number } | null {
  if (entry.length < 64) return null;
  const head = Buffer.from(entry.subarray(0, Math.min(204, entry.length)));
  if (Buffer.from(head.subarray(0, 9)).toString('ascii') !== 'TEXV0005\0') return null;
  const flags = head.readUInt32LE(22);
  if ((flags & 32) === 0) return null;
  const idx = head.indexOf('ftyp');
  if (idx < 8) return null;
  const boxStart = idx - 4;
  const size = head.readUInt32BE(boxStart);
  if (size < 16 || boxStart + size > entry.length) return null;
  return { offset: boxStart };
}

export async function showSceneFallback(info, deps): Promise<'video' | 'frame' | 'preview' | 'none'> {
  const videoUrl = await probeEmbeddedVideo(info.id);
  if (videoUrl && (await deps.layer.showVideo(videoUrl)) === 'ok') return 'video';
  const frameUrl = `/wallpapers/frame/${info.id}`;

```ts
export interface RotationSchedulerDeps {
  getPool: () => WallpaperInfo[];
  getCurrentId: () => string;
  select: (id: string) => Promise<void>;
  isPaused: () => boolean;
  intervalMs: number;
  order?: RotationOrder;
  now?: () => number;
}
export function createRotationScheduler(deps: RotationSchedulerDeps) {
  let timer: number | null = null;
  const failed = new Set<string>();
  let stopped = true;
  const clear = () => { if (timer !== null) { clearTimeout(timer); timer = null; } };
  const schedule = () => {
    clear();
    if (stopped) return;
    timer = window.setTimeout(() => { void tick(); }, deps.intervalMs);
  };
  const tick = async () => {
    if (stopped) return;
    if (deps.isPaused()) { schedule(); return; }
    const pool = deps.getPool().filter((w) => !failed.has(w.id));
    const next = pickNext(pool, deps.getCurrentId(), deps.order ?? 'sequential');
    if (!next) { schedule(); return; }
    try { await deps.select(next.id); } catch { /* 单次失败不终止轮播 */ }
    schedule();
  };
  return {
    start() { stopped = false; schedule(); },
    stop() { stopped = true; clear(); },
    setConfig(cfg: { intervalMs?: number; order?: RotationOrder }) { /* 更新 deps 并 schedule() */ },
    notifyManualSelect() { failed.clear(); schedule(); },
    markFailed(id: string) { failed.add(id); },
    setPaused(p: boolean) { if (p) clear(); else schedule(); },
    status() { /* { enabled, poolSize, nextInMs } */ },
  };
}
```

注意：`deps.intervalMs/order` 需可变配置 → 用内部 `cfg` 对象，`createRotationScheduler` 接收初始值、`setConfig` 更新。
